Уведомления в Telegram

При смене статуса экрана (онлайн/офлайн) бот отправит сообщение. Бот создаётся в @BotFather, Chat ID — через @userinfobot.

Для канала: укажите ID вида -1001234567890 и добавьте бота в канал как администратора (право «Публикация сообщений»).

Резервное копирование

Резервное копирование настроек: данные папки data/ (настройки, плейлисты, экраны, авторизация), загруженный логотип и заставка «вне часов» — в архив в папке backups/.

От 10 до 90. По умолчанию — 30.
Бэкап запускается автоматически в выбранные день/время (пока работает сервер).
Часовой пояс — из раздела «Расписание».
Числа 1–31 через запятую. Например: 1, 10, 20.

Запуск вручную: кнопка «Сделать бэкап» (можно задать имя) или npm run backup. Подробнее — DEPLOY.md.
