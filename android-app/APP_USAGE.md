# Логика использования приложения NeoFit TV

## Запуск приложения

1. **Проверка версии**  
   При каждом запуске сравнивается текущая версия APK с сохранённой. Если версия выросла (обновление или первый запуск), все настройки сбрасываются.

2. **Есть сохранённый URL плеера**  
   → Открывается **плеер** (WebView). Показывается заставка загрузки, затем контент. При ошибке сети — экран с обратным отсчётом и кнопками «Повторить» / «Настройки».

3. **Нет сохранённого URL плеера**  
   → Открывается **экран привязки** (QR + код + кнопка «Ручная настройка»).

---

## Экран привязки (первый запуск или после сброса)

- Поле **URL сервера** (по умолчанию из настроек, например https://s9a.ru).
- Кнопка **«Получить код»** — запрос к серверу `POST /api/pair/init`; при успехе отображаются:
  - **QR-код** (ссылка вида `https://сервер/pair?code=XXXXXX`);
  - **символьный код** (6 символов).
- Администратор на другом устройстве открывает эту ссылку (по QR или вводу кода), выбирает экран и нажимает «Привязать». Приложение на ТВ периодически опрашивает `GET /api/pair/:code`; при статусе `paired` сохраняет URL плеера и переходит в плеер.
- Кнопка **«Ручная настройка»** — переход в настройки с **пустыми** полями «URL сервера» и «ID экрана». Пользователь вводит данные вручную и нажимает «Сохранить и запустить».

---

## Настройки (ручной ввод)

- URL сервера, ID экрана, проверка соединения, смена PIN.
- При открытии **с экрана привязки** поля URL и ID экрана изначально пустые (без подстановки сохранённых значений).
- «Сохранить и запустить» — сохранение `player_url` и переход в плеер.

---

## Плеер

- Воспроизведение контента по сохранённому URL.
- Долгое нажатие (5 сек) — запрос PIN и переход в настройки (или смена PIN при первом запуске).
- Кнопка «Назад» заблокирована (киоск-режим).

---

## Привязка по флешке

- При подключении флешки с файлом `signage.txt` (формат Properties или одна строка — URL) приложение применяет конфигурацию и перезапускает плеер.

---

## Автозапуск

- После загрузки системы (BOOT_COMPLETED / QUICKBOOT_POWERON / HTC_QUICKBOOT_POWERON) запускается сервис, который открывает MainActivity (плеер или экран привязки в зависимости от наличия `player_url`).
