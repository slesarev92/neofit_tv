# Откат к предыдущим версиям

Версии зафиксированы тегами Git. Актуальный список тегов смотри в репозитории: `git tag -l`.

**Откатить весь проект к состоянию нужной версии (например v1.5):**
```bash
cd /opt/digital-signage
git fetch --tags
git checkout v1.5
```

После этого рабочая копия будет в состоянии на момент выбранной версии. Чтобы вернуться к последним изменениям: `git checkout main` (или вашу основную ветку: master/main).

**Восстановить только отдельные файлы из версии:**
```bash
git checkout v1.5 -- путь/к/файлу
```

**Проверка, что откат работает:**
```bash
cd /opt/digital-signage
git checkout v1.5
cat package.json | grep '"version"'   # для v1.5 должно быть "version": "1.5.0"
git checkout main                      # вернуться к текущей ветке
```

**Список всех версий (тегов):**
```bash
git tag -l
```
