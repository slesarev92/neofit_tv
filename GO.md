## Прошлая сессия — 2026-10-07

**Тема:** Soham — в плейлисте видео и картинки, на экранах играет только видео.

**Что сделано:**
1. Root cause в `public/js/player.js`: таймер картинки сверял текущий элемент по ссылке (`items[currentIndex] === item`), а каждый poll подменяет `currentPlaylist` новым объектом. При `imageDuration` (45 с) > `pollInterval` (10 с) таймер не срабатывал → картинку переключал watchdog через 90 с и засчитывал ошибку → после 3 циклов картинки пропускались до авто-перезагрузки в 04:00. Фикс — сравнение по `id` (`isCurrentItem()`), коммит `2d9d6f1`. Проверено симуляцией плеера в node (fake timers, NativePlayer-стаб): до — 6 картинок/22 видео за 30 мин, после — 24/13.
2. Задеплоено на **все три** сервера (`git pull && pm2 restart`), health OK, снаружи отдаётся новый `player.js`. На приставки фикс доедет после ближайшей перезагрузки плеера (04:00 или перезапуск приложения) — `player.js` кешируется WebView/SW.
3. Отдельным коммитом `370cb91` закоммичены висевшие доки по certbot webroot (Soham, 2026-10-05).

5. **SW: обновления плеера доходили до приставок 1–3 суток** (HTTP-кеш `max-age=86400` + Blink memory cache на `location.reload()` мимо SW). Фикс в `public/sw.js` (`07c25ee`, `be2e651`): ревалидация `no-cache`, install `reload`, ответ shell с `Cache-Control: no-cache`, оффлайн-fallback `force-cache`. Проверено headless Chrome (puppeteer-core из scratchpad) на локальной копии и проде Soham: новая версия исполняется со 2-й перезагрузки, оффлайн-загрузка с полным и пустым shell-кешем работает (старый SW при пустом shell-кеше отдавал `Offline`). Задеплоено на все три сервера. **Приставки:** на них ещё старый SW → фикс картинок доедет за 2 перезагрузки страницы (2 рестарта приложения подряд, либо 04:00 8.10 + 04:00 9.10).
4. **NeoFit: env перенесён из PM2 в `.env`.** На сервере `ecosystem.config.js` был локально правлен (захардкоженные env, включая `SESSION_SECRET`, и `BASE_URL=http://` → кука сессии без `Secure`). `.env` уже содержал те же значения (secret совпадал, `BASE_URL=https://`). Сделано: бэкап в `/root/env-migration-20261007-121405/`, `git checkout ecosystem.config.js`, `pm2 delete && pm2 start ecosystem.config.js && pm2 save`. Итог: git clean, секрета нет в `dump.pm2`, `cookieSecure=true` (как на Soham/LabGym), сессии сохранены, плееры опрашивают 200. Откат: вернуть файл из бэкапа + `pm2 delete signage && pm2 start ecosystem.config.js && pm2 save`.

## Прошлая сессия — 2026-07-14

**Тема:** Soham — фикс обработки видео + диагностика перебоев доступа к панели.

**Что сделано:**
1. **Баг «Cannot find ffmpeg» на Soham.** Root cause: при деплое (one-off скрипт из scratchpad) выпал `apt install ffmpeg`. `fluent-ffmpeg` ищет системный бинарник в PATH — его не было (`which ffmpeg ffprobe` → NOT FOUND, в логах `Cannot find ffmpeg`/`Cannot find ffprobe`). Фикс: `apt install -y ffmpeg` → ffmpeg 6.1.1 (`/usr/bin/ffmpeg`+`ffprobe`), self-test libx264 OK, `pm2 restart signage`, health `{"ok":true,"version":"3.6.0"}`. Упавшие загрузки нужно **перезалить** (помечены failed, авто-ретрая нет). Зафиксировано в `docs/DEPLOYMENT.md` (шаг apt + строка в «Типовые проблемы»).
2. **Перебои доступа к панели («иногда нет соединения, с того же компа»).** Серверная сторона чистая: PM2 online (2 рестарта), RAM 1.4 ГБ free, OOM нет, load низкий; nginx только IPv4 (AAAA-записи нет → IPv6-гипотеза отпала), без limit-зон, cert до 2026-10-04; fail2ban банит только sshd, ufw off; 10/10 внешних HTTPS-проб успешны ~50 мс. Вывод: **не падение сервера**, перебои на сетевом пути (провайдер/DPI/локальная сеть). Пользователю выданы шаги самодиагностики на момент сбоя (ping/tracert к IP, проверка DNS, другой браузер/сеть). Не воспроизвелось со стороны сервера.
