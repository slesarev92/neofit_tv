# Trainers screensavers — research digest (2026-10-09)

Выжимка трёх исследований (практика клубов, читаемость/кегли, визуальные паттерны). Основа для брейншторма v3. Журнал решений — `docs/trainers-1c.md`.

Оговорка: независимых исследований по экранам в залах почти нет; большинство цифр эффекта — заявления вендоров (CrownTV, OptiSigns, ScreenCloud, Rise Vision). Российские сети (World Class, DDX, X-Fit) экраны в залах не публикуют.

## Читаемость (самое важное для нас)

32–34″ 16:9 → высота экрана ~400–423 мм → **~2,6–2,7 px/мм** в 1080p. Высота заглавной = дистанция × tan(угла); норма 20–22′ (≈6,4 мм/м), минимум 16′ (≈4,7 мм/м), правило вывесок 1″/10 футов (≈8,3 мм/м). font-size ≈ cap / 0,72 (Manrope).

| Дистанция | минимум | норма | заголовки |
|---|---|---|---|
| 2 м | 35 px | 49 px | 63 px |
| 3 м | 52 px | 72 px | 94 px |
| 4 м | 70 px | 96 px | 125 px |
| 6 м | 105 px | 145 px | 188 px |

- **v2 был в 2–3 раза мельче нормы**: тексты 23–36 px, чипы 30 px, расписание 32–36 px.
- Объём: ≤3 строк основного текста, ≤15–20 слов на слайд, одна точка фокуса, ≤3 элементов информации (3×5 rule).
- Время показа: **T = 3 с + 0,6 с × слов**, мин 5, макс 20 с. Расписание: 4 с + 1,5 с × строк (~13 с на 6 строк).
- Расписание: при строке 72 px физически ≤8 строк, рекомендовано **≤6 строк на слайд**, пагинация «1/3».
- Safe area: 96 px по бокам, 54 px сверху/снизу (5%, Android TV); фон — на весь кадр.
- Начертания: не тоньше SemiBold; капс — только для коротких меток (с трекингом +4–8 %), основной текст в смешанном регистре.
- Контраст: лайм #8dc63f на чёрном 10,3:1 — ок. Чистый чёрный в ярком зале даёт «иррадиацию» белого — фон #0e0e0e–#141414.
- Финальный критерий — проверить на реальном ТВ в зале с 4 и 6 м.

## Что работает в клубах

- Экран = одна задача. Контент по зонам: зал весов/кардио — «фоновый», без жёстких продаж (есть и противоположное мнение — тестировать); лобби — расписание, промо.
- **Тренер:** клиенту важны живое лицо, «с чем помогу» (цели простыми словами), результаты клиентов, затем опыт; регалии — вторичны (опросы AU/NZ, Бангкок, UK). Нужен призыв: где записаться.
- **2–4 тренера в петле, ротация ежедневно/еженедельно** — иначе экран превращается в обои. Тренеры именно этого здания.
- **Расписание:** «Сейчас / Далее» + остаток дня; только будущие занятия; цвет по типу/интенсивности; отмены и замены — выделять; **устаревшее расписание хуже никакого** → генерация не реже раза в час.
- Петля в зоне весов ≤2–3 мин (чтобы за отдых между подходами ключевой слайд попался).
- Ошибки: много текста, мелкий шрифт, несколько сообщений на слайде, неизменная петля месяцами, «пейте воду».
- Эффект мерить самим (запросы на ПТ, заполняемость групп по тренерам в 1С — до/после, здание с экранами vs без).

## Визуальные паттерны

- Спортивная ТВ-графика: читается за 1–2 с; текст на сплошной подложке, не на фото; одна крупная цифра как точка входа (карточки EA FC); наклонные срезы плашек; гигантская фамилия за вырезанной фигурой.
- Человек на слайде: фигура 45–60 % высоты кадра; имя 140–200 px; ≤3 фактов; одна большая цифра 250–350 px; 2–3 тега.
- Расписание: Now/Next как табло вылетов; колонки по залам (3–4 на 1920); таймлайн с линией «сейчас»; разбивка утро/день/вечер; строка с круглым фото тренера; «тренер + его занятия».
- Цвет по типу занятия (Orangetheory — цвет считывается раньше текста); лайм оставить под «сейчас» / главный акцент.
